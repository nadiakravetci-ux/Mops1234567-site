# mops1234567 — TikTok landing page

This is a standalone static website prepared for GitHub Pages.

## Files
- `index.html` — the website
- `assets/avatar.png` — channel avatar

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site.

The site does not require a Claude login or a server-side runtime.
